# Swarm cost routing

Use swarms only when delegation materially improves the task outcome. Treat delegation as a cost-sensitive routing mechanism, not a default workflow.

For bounded, low-risk work such as lookups, narrow inspection, mechanical edits, and focused validation, select the least expensive model that can reliably complete the assigned outcome. Reserve stronger models for tasks that need substantial reasoning, complex implementation, security-sensitive judgment, or integration decisions.

Do not change the coordinator's model. Do not add workflow, planning, communication, review, or lifecycle instructions: those are provided by Jcode's built-in agent system.
